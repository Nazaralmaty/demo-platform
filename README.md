# GSC Study · демо-экосистема

Витрина для выдуманной школы **GSC Study** (тема снята с gscstudy.com и её
Instagram: океан-синий #135685, пурпур #B1005A, золото, зелёный, плоские карточки
30px, Montserrat + Golos Text с казахскими буквами). Это не перекрашенный
шаблон: экосистема собрана под школу целиком — от логотипа до текстов
уведомлений.

Открывается по ссылке на любом устройстве: обычные HTML-файлы, без сборки,
без backend и базы, прогресс — в localStorage. Демо-мир — 16 октября 2026:
7 учеников, 3 учителя, два отчётных периода.

## Как устроено внутри

Все служебные экраны читают одни выдуманные данные из `app/data.js`:
ученики, уроки, отметки, подтверждения. Поэтому цифры на кабинете учителя,
в админ-кабинете, в контроле уроков и в оповещениях не могут разойтись.
Темы и домашние задания уроков — настоящие, из курса в `app/course.js`
(56 уроков). Состояние живёт в памяти вкладки: обновил страницу — всё
вернулось как было.

Деньги: начислено по отметкам учителя → подтверждено клиентом (и качество
выше двух) → к выплате. Спор, молчание клиента, урок без отметки и оценка
1–2 висят «на проверке» и в выплату не уходят, пока администратор не
разобрался. Ссылка в уведомлении ведёт на экран подтверждения этого ученика.
