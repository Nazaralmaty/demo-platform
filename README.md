# GSC Study · демо системы школы

Витрина для школы **GSC Study** (тема снята с gscstudy.com и её Instagram:
океан-синий #135685, пурпур #B1005A, золото, зелёный, плоские карточки,
Montserrat + Golos Text с казахскими буквами). Показывает директору школы
не макет, а работающую систему на выдуманных учениках. Это полная
платформа для школы, у которой своей нет: курс для учеников (56 уроков,
видеоуроки-мультфильмы, задания, словарь), кабинет учителя, дашборд
владельца, единая методика, контроль уроков с зарплатой, возвраты по акту,
гарантии по фактам и оповещения.

Обычные HTML-файлы, без сборки и без базы. Открывается по ссылке на любом
устройстве. Демо-мир — понедельник, 19 октября 2026: 7 учеников, 3 учителя,
первая половина октября закрыта, запросы клиентам ушли 16-го.

Обложка: **https://nazaralmaty.github.io/demo-platform/demo.html**

## Как это работает

1. Учитель отмечает урок. Это заявка, а не деньги.
2. Два раза в месяц клиент получает ссылку и подтверждает уроки.
3. Подтверждённое с оценкой 3–5 уходит в зарплату само.
4. Всё остальное — в очередь администратора, и деньги по нему не
   выплачиваются, пока он не решит:

| Вопрос | Когда |
|---|---|
| Учитель и клиент расходятся | учитель отметил, клиент ответил «не было» |
| Подозрительная отметка | урок не по графику, сверх графика, отмечен задним числом или после ответа клиента — и клиент его не подтверждал |
| Урок был, отметки нет | клиент подтвердил урок по графику, учитель его не отметил |
| Клиент не уверен | неоднозначный ответ |
| Низкая оценка | 1–2 из 5 |
| Клиент не ответил | 2 дня без ответа после запроса |

В демо все семь случаев уже есть. Сценарий показа — на обложке: учитель
отмечает урок → Тимур (молчал три дня) отвечает по ссылке → спор
появляется в контроле и в Telegram админа → админ решает → ведомость и
дашборд пересчитаны.

## Возвраты, гарантии, методика

Каждое действие ученика в платформе записывается с датой и временем:
вход, видеоурок, слова, задания (с результатом), чтение, игра. Из этого
журнала и журнала уроков считается всё остальное.

**Возврат.** Доступ к платформе — результат интеллектуальной деятельности
школы и оказанная услуга с первого входа. Клиент просит вернуть всю сумму —
школа возвращает оплату за вычетом стоимости доступа (если клиент входил) и
уроков, которые он сам подтвердил по ссылке. В демо мама Аружан через две
недели после покупки пакета за 120 000 ₸ просит вернуть всё:

| | |
|---|---|
| Оплачено 4 октября | 120 000 ₸ |
| Доступ к платформе (вход 4 октября, 19:41) | − 40 000 ₸ |
| Уроки 6, 8, 10, 13 октября, подтверждены клиентом | − 4 × 5 000 ₸ |
| **К возврату** | **60 000 ₸** |

Ещё два урока ждут ответа клиента и в расчёт не входят. Акт собирается из
журнала: когда принята оферта, что открывал, какие уроки и когда
подтвердил. Сумма доступа — правило школы, меняется на экране «Гарантии».

**Гарантия.** Действует, пока ученик выполняет условия школы: посещаемость
(90%), домашка в платформе за 2 дня после урока (80%), результат заданий
(70%). Тимуру обещали IELTS 7.0: на уроки он ходит, а домашки — 0 из 5.
Справка для клиента — условия из оферты рядом с фактом из журнала,
пропущенные домашки по датам.

**Методика.** Один урок курса — две встречи с учителем: правило и слова,
потом практика. До урока ученик смотрит видео, после — делает слова или
задания. Урок не по курсу, домашка не делается подряд, к урокам не
готовится — это отступления, их видно владельцу и учителю.

Условия возврата и гарантии — образец для юриста школы, а не юридическая
консультация.

## Как устроено внутри

| Файл | Что это |
|---|---|
| [`app/control.js`](app/control.js) | **Движок контроля**: периоды, статус урока, подозрения, очередь, деньги, ведомость, тексты сообщений. Тот же файл работает в 1english-platform и считает там настоящую зарплату |
| [`app/school.js`](app/school.js) | **Движок школы**: факты по ученику из журнала платформы (подготовка, домашка, результат, активность), гарантия, расчёт возврата, акт, справка, пункты оферты, отступления от методики |
| [`app/data.js`](app/data.js) | Демо-мир: учителя, ученики, договоры, уроки — сгенерированы по графику каждого ученика, темы из курса. Действия в платформе, запрос на возврат, правила школы. Действия учителя, клиента и админа. Общее состояние в `localStorage` |
| [`app/eco.js`](app/eco.js) | Шапка с навигацией, окно, тост, перерисовка при смене данных |
| [`app/eco.css`](app/eco.css) | Дизайн-система служебных экранов: только токены темы школы, тёмная тема, таблицы складываются в карточки по ширине своей карточки |
| [`app/confirm_ui.js`](app/confirm_ui.js) | Экран клиента. Тоже общий с 1english-platform, там он ходит в базу |
| [`archive/v1/`](archive/v1/) | Прошлая версия служебных экранов — для сравнения «было → стало» |
| [`1english/`](1english/) | **Тестовая копия 1English** с контролем уроков (ветка `claude/dreamy-allen-bs64xc` из 1english-platform): дашборд с вкладкой «Контроль», кабинет учителя, экран клиента, SQL-патч и тесты. Всегда на тестовых данных, в базу 1English не ходит. План проверки — [1english/index.html](1english/index.html) |

Состояние общее для всех экранов: отметили урок в кабинете учителя — он
сразу в контроле и в журнале событий. Открыто в двух вкладках — вторая
подтягивается сама. «Сбросить» в шапке возвращает демо-мир как был.
Данные лежат только в браузере того, кто смотрит.

## Проверки

```bash
node app/check.mjs            # курс: 56 уроков, банк слов
node app/check_control.mjs    # движок и демо-мир: деньги руками, 7 типов очереди, действия, сброс
node app/check_school.mjs     # возврат Аружан руками, гарантии, справка, оферта, методика
node app/check_e2e.mjs        # Chromium: сценарий показа по всем экранам, 390 и 1280, ошибки консоли
cd 1english && node app/check_control_e2e.mjs   # копия 1English: контроль, учитель, клиент, ни одного запроса наружу
```

`check_e2e.mjs` нужен Playwright (`npm i -g playwright && npx playwright
install chromium`). Он сам поднимает сервер и проходит показ так, как его
пройдёт директор: учитель → клиент → контроль → обзор → методика →
возврат → гарантия → оповещения.
